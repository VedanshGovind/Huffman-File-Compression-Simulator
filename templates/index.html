How it works

    

      
1. Frequency tableCount how often each character appears in the file.

      
2. Min-heap treeRepeatedly merge the two least-frequent nodes (via heapq) until one Huffman tree remains.

      
3. Codes & encodeWalk the tree (left = 0, right = 1) to build variable-length codes - frequent characters get shorter ones. The tree is pickled into the file header so it decompresses on its own.
